# R-eadership 受付から発行までの手順書（中村用）

R-eadership は **1つの学校に、1つのスプレッドシートとGAS** を用意します（個人情報が学校どうしで混ざらないように）。
そのため、入金を確認したあとの「発行」では、スプレッドシートのコピーとデプロイの作業を中村が行います。

使うもの
- スプレッドシート **R-eadership_受付**（申込一覧。GAS「R-eadership 受付API」）
- スプレッドシート **R-eadership_ひな形**（データの入っていない学校用。これをコピーして使う）
- リポジトリ r-eadership の `frontend/user/js/schools.js`（学校コード → GASのURL の対応表）

---

## 1. お申し込みが来たとき（自動）
1. 学校がLPから申し込むと、「申込一覧」に1行ふえ、状態は「入金待ち」になる
2. 学校には受付メール（請求書のPDFつき・振込先・支払期限14日）が自動で届く
3. 中村には「お申し込みがありました」のメールが届く

支払期限を過ぎた「入金待ち」の行は、赤くなります。

## 2. 入金を確認したとき
1. 銀行の入金を確認する（振込名義の前に、申込番号の数字4けたが付いている）
2. 「R-eadership_受付」を開き、「申込一覧」で、その申込の行のどこかをクリックする
3. メニュー「R-eadership受付」→「選んだ申込の「入金を確認した」（学校にメールを送る）」→「はい」
   - 状態が「入金確認」になり、学校に「ご入金を確認しました」のメールが届く

## 3. 学校の環境を用意する（発行）
**順番が大事です**：先にデプロイと schools.js の登録をしてから、最後に setupSchool（発行メールが送られる）を実行します。

### 3-1. ひな形をコピーする
1. Googleドライブで「R-eadership_ひな形」を右クリック →「コピーを作成」
2. コピーの名前を「R-eadership_学校名」（例：R-eadership_沖縄○○専門学校）に変える
3. 学校用のフォルダに移す（ほかの人と共有しない）

### 3-2. 学校コードを決める
- 英大文字と数字の3〜10文字。ほかの学校と重ならないもの（例：OKN01）
- `schools.js` にすでにある学校コードと重ならないことを確かめる

### 3-3. Webアプリとして公開する
1. コピーしたスプレッドシートを開き、「拡張機能」→「Apps Script」
2. 右上の「デプロイ」→「**新しいデプロイ**」（この学校では、これが最初のデプロイ）
3. 種類「ウェブアプリ」、説明「学校名 初回」、次のユーザーとして実行「自分」、アクセスできるユーザー「全員」→「デプロイ」→ 承認
4. 表示された「ウェブアプリ」のURL（…/exec）をコピーする

### 3-4. schools.js に1行足して push する
1. VS Code で `frontend/user/js/schools.js` を開く
2. `DEMO: '…',` の下に、次のような1行を足す（最後のカンマを忘れない）
   ```js
   OKN01: 'https://script.google.com/macros/s/……/exec',
   ```
3. PowerShell で
   ```powershell
   git add frontend
   git commit -m "学校を追加：OKN01"
   git push
   ```

### 3-5. 学校を登録して、発行メールを送る
1. 学校のGASの画面で、左の歯車（プロジェクトの設定）→「スクリプト プロパティ」に5つ入れる
   - `SCHOOL_NAME`：学校名（申込一覧の学校名）
   - `SCHOOL_CODE`：3-2で決めた学校コード
   - `ADMIN_ID`：学校管理者の教員ID（ふつうは `admin`）
   - `ADMIN_NAME`：学校管理者の名前（申込一覧の担当者名）
   - `ADMIN_EMAIL`：発行メールを送るメールアドレス（申込一覧のメールアドレス）
2. push してから1〜2分待つ（schools.js が公開されるのを待つ）
3. `Auth.gs` を開き、`setupSchool` を実行する
   - ログに「発行メールを ○○ に送りました」と出れば完了。仮のパスワードはメールにだけ書かれ、どこにも残らない
   - `ADMIN_EMAIL` は自動で消える
4. `Students.gs` を開き、`setupDailyJobs` を実行する（卒業生の自動削除。承認が出たら許可）

### 3-6. 申込一覧を「発行済み」にする
1. 「R-eadership_受付」の「申込一覧」で、その申込の行をクリック
2. メニュー「R-eadership受付」→「選んだ申込を「発行済み」にする」→ 学校コードを入れて OK

---

## 4. 学校管理者がパスワードを忘れたとき
1. 学校のGASの「スクリプト プロパティ」に `ADMIN_ID`（その学校管理者の教員ID）と `ADMIN_PASSWORD`（新しい仮のパスワード。8〜64文字）を入れる
2. `Auth.gs` の `resetAdminPassword` を実行する（`ADMIN_PASSWORD` は自動で消える）
3. 本人であることを確かめてから、新しい仮のパスワードを伝え、ログイン後に「パスワード変更」で変えてもらう

## 5. 学校の利用を止めるとき
1. `schools.js` から、その学校の行を消して push する（ログインできなくなる）
2. 学校のGASで「デプロイ」→「デプロイを管理」→ そのデプロイを「アーカイブ」
3. 利用規約のとおり、学校の求めに応じて学生名簿・応募をCSVで渡したあと、スプレッドシートを削除する

## 6. プログラムを直したとき（大事）
- 学校ごとにGASが別なので、**GASを直したら、すべての学校のGASに同じファイルを貼り付けて「新バージョン」で更新**する
- 画面（frontend）は1つなので、push すれば全部の学校に反映される
- 「R-eadership_ひな形」のGASも、同じように更新しておく（次の学校が古いままにならないように）

## 一度だけ行う準備

### A. 受付用のスプレッドシート（R-eadership_受付）
1. 新しいスプレッドシート「R-eadership_受付」を作る（共有しない）
2. 「拡張機能」→「Apps Script」。プロジェクト名を「R-eadership 受付API」にする
3. `コード.gs` を `reception/Code.gs` の内容にし、ファイル「Invoice」を足して `reception/Invoice.gs` の内容にする
4. スクリプト プロパティに `ADMIN_EMAIL`（中村のメールアドレス）と `BANK_INFO`（振込先）を入れる
5. `setupReception` を実行 → `testInvoice` を実行して、見本の受付メールと請求書のPDFが届くか確かめる
6. 「新しいデプロイ」（ウェブアプリ・自分・全員）→ URLを `frontend/user/js/config.js` の `APPLY_API_URL` に入れて push

### B. ひな形のスプレッドシート（R-eadership_ひな形）
1. 開発用の「R-eadership_学校向け就職管理システム」を「コピーを作成」→ 名前を「R-eadership_ひな形」にする
2. コピーの「Apps Script」で、スクリプト プロパティに `RESET_OK` ＝ `はい` を入れる
3. `Auth.gs` の `resetForTemplate` を実行する（データ・スクリプト プロパティ・トリガーが全部消える）
4. 学生・教員などのシートが見出しだけになっていることを確かめる
