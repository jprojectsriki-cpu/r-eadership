PROBLEM & SOLUTION

就職指導現場の課題を解決

エクセルや紙での管理で起きていた情報の分断や集計の負担を、「R-eadership」の一元管理で解消します。

従来の管理方法の限界

  • エクセル管理の散逸・先祖返り：クラスごとにファイルが分かれ、就職対策室との全体集計に膨大な時間がかかる。
  • 面接直前のフォロー漏れ：学生がいつ面接を受けるのかをタイムリーに把握できず、アドバイスが間に合わない。
  • 引き継ぎ・指導履歴の不透明化：面接の手応えや課題感が口頭報告にとどまり、組織としての蓄積にならない。

R-eadership による解決

  • リアルタイム一元データベース：担任の入力がすぐに反映。CSV出力機能で、調査・報告資料もワンクリックで出力。
  • 3日前選考自動リマインド：直近の選考日程をダッシュボード上部に自動で表示。事前指導を徹底できます。
  • 全履歴タイムライン化：応募から内定までのすべての段階と、面接指導のメモを時系列で記録。
KEY FEATURES

R-eadership の主要機能

現場の教員の入力の手間をできるだけ減らし、進路指導の精度を高める機能をそろえています。

学生名簿 ＆ 保有資格マスタ

学籍番号、氏名、所属クラス、取得資格を一元管理。資格の種類やクラスで絞り込めるので、条件に合う学生をすぐに探せます。

クラス・資格による瞬時フィルタリング

エントリー ＆ ステータス追跡

応募企業名、職種、選考の段階（書類送付済、一次・二次・最終面接、内定獲得）をデータで管理。最新の選考状況が、学生のステータスに自動で反映されます。

学生の最新ステータスを自動更新

3日前自動リマインド通知

3日以内に面接を控えている学生を、ダッシュボードの上部に自動でハイライト表示。事前の面接練習やアドバイスの漏れを防ぎます。

面接スケジュールの自動抽出アラート

個別選考タイムライン

学生ごとの応募履歴、各面接の手応え、指導記録をタイムラインで見える化。教員どうしの引き継ぎもスムーズです。

ワンクリックCSV出力

すべてのエントリーデータを、ワンクリックでCSVに出力。行政機関への提出資料や、学内の集計資料づくりに使えます。

クラス・ユーザー柔軟管理

年度更新のときのクラス編成、担当教員の割り当て変更、教員アカウントの追加や設定変更を、画面上でかんたんに行えます。

ACCESS CONTROL

校内運用に適した2階層の権限設計

学校の組織に合わせて、「学校管理者」と「一般教員」の2つの権限を用意。情報の漏えいを防ぎ、スムーズな校内運用を実現します。

SCHOOL ADMIN

学校管理者（統括・就職対策室向け）

全校生の就職進捗の閲覧、教員アカウントの発行・停止、学科・クラスと資格マスタの設定、全体データのCSV一括出力を行えます。

  • 教員アカウントの発行・アクセス制御
  • 学科・クラス・資格マスタの管理
  • 全校生データのCSV出力・報告作成
TEACHER

一般教員（クラス担任向け）

担当クラスの学生登録、選考エントリー状況の更新、面接日程の入力、個別のアドバイス・指導メモの記録に特化した操作ができます。

  • 担当クラスの学生情報の更新
  • 選考の段階・次回面接日程の入力
  • 学生ごとの指導履歴メモの記録
